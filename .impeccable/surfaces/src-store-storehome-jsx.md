SCOPE AND MODE: storefront home plus one detail page per game plus a full-screen play route. Persuade. Primary user is an evaluator judging a solo dev's work; secondary user is a player who came to play. Job: judge the craft from real evidence, then start playing in one click. Proof: live screenshots of the running games, counts read from source, the games themselves. Constraint: no cart, no purchase, no invented social proof. PT-BR.

DIRECTION: oscilloscope signal bench. A store that presents itself as an instrument panel — every claim is a measured reading on an etched graticule. Chosen by the user over the seed's assigned direction (seed f81deb1e).

## Direction contract

THESIS: A game store is an instrument that measures a body of work. It refuses the capsule-and-badge row of the Steam clone and the narrative hero of the portfolio page; it shows the work as readings.

OWN-WORLD: near-black bench (#0d0d0d), off-white ink (#f2f0e9), signal red (#d81f1f) reserved for measurement and change only. Etched graticule of ten divisions under the readout band. Archivo Black for display figures, JetBrains Mono for every label and figure. 3px rules, zero corner radius, zero shadow, zero gradient. Three colors, never a fourth.

STORY: The visitor learns there are exactly two games, sees each one's real volume measured, reads that neither needs installing, and can be playing within one click from any page.

FIRST VIEWPORT: header band with the ÓRBITA mark; readout band with CH1 count and CH2 volume as large display figures; channel rows beneath, each a control showing name, genre, a segmented meter, a figure, and JOGAR; a hint line stating zero requirements. The store is unmistakable by the first viewport.

FORM: oscilloscope signal bench. Competitive challenger on the seed's product-clarity axis, declined on audience identification; the user chose it. That loss is answered in the build, not argued: each channel row is a control rather than a link, and each anchors on a real screenshot so the instrument is legibly about games. Seed key f81deb1e.

RAISES: from the mirrored hall, one vast horizontal register so the page is a room and not a list. From the brine jars, each row carries the visitor's own real progress read from that game's localStorage. From the one-bit desktop, the three-color limit is stated once and obeyed absolutely. From the vellum map, one red rule is the spine of the page, from the mark through every channel to the support band.
